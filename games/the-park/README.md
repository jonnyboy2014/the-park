# The Park

A tiny 3D prototype made with Three.js.

## Goal
Search the park buildings and cabinets to find 3 keys, then unlock the exit gate.

## Controls
- Mouse: look around
- WASD or arrow keys: move
- Space: jump
- E: open doors, search cabinets, pick up keys, unlock gate
- Esc: release mouse

## Easy Changes
- In `game.js`, change `keysRequired` to make the game easier or harder.
- Buildings are created with `buildBuilding`, so adding one line adds another place to explore.
